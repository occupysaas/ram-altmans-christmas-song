# Brief: character layers cut from stills

Use your image_gen tool. Attached: stills 07, 18, 19, 36 and cast sheets public/cast/*.png. Look at every result; regenerate if off-model, if the figure is not in exactly the same place/size as in its still, or if any text/letters/logos appear. Do not ask questions. Stop when every file exists and you have checked it. Write a contact sheet to out/sheets/cutouts-cleanup.png (not into public/).

## Style (most important)
A 1960s made-for-TV Christmas cartoon special look: thin, slightly wobbly black ink outlines, flat cel colors with no gradients on characters, watercolor-wash backgrounds with dry-brush texture, curly swooping shapes, exaggerated spindly limbs, slightly limited palette (deep teal-blue night, snow white with lavender shadow, holly red, warm window yellow, sickly villain green). It must be an ORIGINAL design: do not copy the Grinch, Whoville, Scrooge McDuck or any existing character.
No text, letters, numbers or logos anywhere in any image.

Every layer is a FULL 1600x1200 frame on flat magenta #FF00FF: repaint the still with EVERYTHING except the named figure replaced by flat magenta, so the figure stays at exactly its original position, size and pose (pixel-aligned with the still as closely as you can). No shadows on the magenta, no magenta inside the figure. Save in public/sprites/layers/NN/.
